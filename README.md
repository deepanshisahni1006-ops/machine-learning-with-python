# Music Recommender Machine Learning Model 🎵🎧

A machine learning project built to predict and recommend music genres based on user characteristics like age and gender using a Decision Tree classifier.

## 🚀 Overview
This project uses Python and popular data science libraries to train a Decision Tree model on user data (`music.csv`). It processes the dataset, trains the classifier, visualizes the decision-making tree structure, and outputs custom music recommendations.

## 🛠️ Tech Stack & Libraries
* **Python**: Core programming language for data analysis and modeling.
* **Pandas**: For data loading, manipulation, and handling CSV files.
* **Scikit-Learn (sklearn)**: For building, training, and evaluating the Decision Tree machine learning model.
* **Graphviz / Dot Files**: For visualizing the decision tree architecture.

## ✨ Features
* Data preprocessing and feature extraction from CSV datasets.
* Training a supervised machine learning model (Decision Tree Classifier).
* Visual representation and plotting of the trained decision tree nodes.
* Accurate music genre recommendations based on input features (age and gender).
